🚀 **Computer Vision Toolkit (OpenCV + Python)**



This repository showcases a mini Computer Vision toolkit developed in Jupyter Notebook using OpenCV. It combines image enhancement, privacy protection, similarity analysis, watermarking, OCR preprocessing, and batch processing utilities.



🔹 Core Capabilities



📷 **Image Processing**



RGB ↔ Grayscale conversion



Resizing and visualization



File export



**🌟 Enhancement**



Auto brightness \& contrast adjustment



Social-media optimized formatting



🔍 **Image Analysis**



MSE comparison



SSIM similarity measurement



🎯 **Object Detection**



HSV-based red color segmentation



🔐 **Privacy Module**



ROI-based Gaussian blur for license plates



🖋️ **Watermarking System**



PNG watermark overlay



Transparency support



Centered and scalable placement



Adjustable opacity



📄 **OCR Preparation Pipeline**



Noise filtering



Threshold-based text enhancement



🖼️ **Collage Generator**



2×2 grid layout creation



🏢 Batch Processing Tool



Automated grayscale conversion for print workflows



🧹 **Noise Removal Module**



Gaussian and Median filtering for scanned documents



🔁 **Standard Execution Pattern**



Each notebook section follows a consistent execution structure:



Image Input → Processing → Visualization → Save Output → Console Confirmation
