# Machine Learning Techniques Case Studies

A collection of real-world inspired machine learning case studies demonstrating preprocessing, feature engineering, and time-series analysis techniques using Python.

---

# Project Overview

This repository demonstrates practical applications of:

- Feature Scaling
- Auto-Correlation Analysis
- Feature Weighting
- Predictive Modeling
- Time-Series Analysis

using healthcare, agriculture, finance, manufacturing, and cybersecurity scenarios.

---

# Case Studies

## 1. Healthcare: Patient Health Risk Prediction
- Technique: Standard Scaling
- Model: Logistic Regression
- Goal: Predict cardiac risk using normalized medical features.

## 2. Agriculture: Seasonal Crop Yield Forecasting
- Technique: Auto-Correlation
- Goal: Detect seasonal crop yield patterns.

## 3. Finance: Creditworthiness Assessment
- Technique: Feature Weighting
- Model: Logistic Regression
- Goal: Identify influential factors in loan approval.

## 4. Manufacturing: Industrial Machine Anomaly Detection
- Techniques:
  - Standard Scaling
  - Auto-Correlation
- Goal: Detect abnormal vibration behavior in robotic arms.

## 5. Cybersecurity: Intrusion Detection
- Techniques:
  - Feature Scaling
  - Random Forest Feature Importance
- Goal: Detect suspicious network activity.
