# Machine Learning Applications in Real-World Domains

## Introduction
This repository presents five machine learning case studies demonstrating the use of unsupervised and supervised learning techniques across different domains.

The implemented methods include:
- K-Means Clustering
- Principal Component Analysis (PCA)
- Artificial Neural Networks (ANN)

---

# Objectives

The main objectives of this project are:

- To apply clustering for customer segmentation
- To reduce high-dimensional datasets using PCA
- To classify complex datasets using neural networks
- To visualize machine learning outputs effectively

---

# Case Study Descriptions

## Case Study 1: Airline Dynamic Pricing
Technique: Cluster Analysis

The airline industry uses customer segmentation to optimize ticket pricing and improve revenue management.

---

## Case Study 2: Parkinson’s Disease Diagnosis
Technique: PCA + ANN

Voice recordings are analyzed to detect Parkinson’s disease using dimensionality reduction and neural network classification.

---

## Case Study 3: Credit Card Fraud Detection
Technique: PCA + ANN

Financial transaction data is processed to identify fraudulent activities efficiently.

---

## Case Study 4: Retail Consumer Trend Mapping
Technique: Cluster Analysis + PCA

Retail transaction data is analyzed to discover hidden customer trends and regional shopping patterns.

---

## Case Study 5: Smart Manufacturing Quality Control
Technique: ANN

Sensor data from manufacturing environments is used to predict defective products automatically.
