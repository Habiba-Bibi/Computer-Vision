**Computer Vision Image Enhancement Project**



This project demonstrates image processing techniques used for improving grayscale images using Python and OpenCV.



**Techniques Implemented**



Image Negative



Log Transformation



Gamma Correction



Contrast Stretching



CLAHE



Intensity Slicing



Libraries Used



OpenCV



NumPy



Matplotlib



**Conclusion**



These enhancement techniques help improve image quality and are widely used in AI, Computer Vision, and image analysis systems.
