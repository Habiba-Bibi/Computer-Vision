# 🖼️ Computer Vision Learning Journey

Welcome to my Computer Vision Lab repository! This is a collection of hands-on exercises I worked on to learn image processing, computer vision, and pattern recognition from basics to advanced concepts.

## 🌟 What You'll Find Here

This repository contains **14 lab exercises** that progressively build your computer vision skills. Each lab is self-contained with theory, code, and real-world applications.

## 📚 Lab Topics

| Lab | Topic | What You'll Learn |
|-----|-------|-------------------|
| 01-02 | **Python & OpenCV Basics** | Install Python/OpenCV, read/display/save images, color conversions |
| 03 | **Contrast Enhancement** | Make dark images brighter, histogram equalization |
| 04 | **Image Transformations** | Create negative images, log transformations, gamma correction |
| 05 | **Edge Detection** | Find boundaries of objects using Sobel, Prewitt, Canny |
| 06 | **Face Detection** | Detect and recognize faces in images and videos |
| 07 | **Gabor Features** | Extract texture patterns (great for fingerprints!) |
| 08 | **Image Search (CBIR)** | Build a system that finds similar images by content |
| 09 | **Object Detection** | Detect cars, people, objects using YOLOv8 |
| 10 | **PSO Optimization** | Use swarm intelligence to find objects in images |
| 11-12 | **Pattern Recognition** | Normalize data, reduce dimensions, cluster, classify |
| 13 | **Letter Recognition** | Teach a computer to read handwritten letters |
| 14 | **Digit Recognition** | Recognize handwritten numbers (0-9) |

## 🎮 Cool Projects You Can Build

- **Photo Enhancer**: Fix dark or low-contrast photos
- **Face Unlock System**: Detect and recognize faces
- **Image Search Engine**: Find similar images by color/texture
- **Traffic Monitor**: Detect cars and pedestrians
- **Handwriting Reader**: Read handwritten digits and letters
- **Quality Inspector**: Detect defects in products
