\# Gabor Vision Lab 🚀



\## 🔍 What is this?

A collection of computer vision experiments using Gabor filters to analyze textures across different domains.



\## 🧪 Experiments Included

\- 🧱 Surface Defect Detection

\- 🏢 Architectural Texture Analysis

\- 🔍 Fingerprint Enhancement

\- 🤖 Texture Classification (SVM)

\- 🙂 Facial Expression Recognition

\- 🛰 Satellite Image Segmentation

\- 🏗 Material Recognition



\## ⚙️ How it Works

Gabor filters analyze images based on:

\- Orientation

\- Frequency

\- Texture patterns



These features are then used for:

\- Detection

\- Classification

\- Segmentation



\## 📊 Results

\- Enhanced texture visibility

\- Accurate classification of materials and patterns

\- Clear segmentation of satellite imagery

\- Effective feature extraction for facial expressions
