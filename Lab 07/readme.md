\# 🔍 Face Recognition Systems (Computer Vision Lab Project)



\## 🚀 What This Project Does

This project builds multiple \*\*AI-powered face recognition systems\*\* using OpenCV, applied to real-world scenarios — all without using a webcam.



\---



\## 🎯 Systems Built



| System | Description |

|------|------------|

| Attendance System | Automatically marks student attendance |

| Access Control | Grants/denies access |

| Celebrity Recognition | Tags famous personalities |

| Intruder Detection | Detects unknown faces |

| Criminal Identification | Matches criminals in CCTV footage |



\---



\## 🧠 Tech Stack

\- Python

\- OpenCV (contrib)
