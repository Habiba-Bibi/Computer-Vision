\# Handwritten Alphabet Recognition Using Deep Learning



\## Abstract



This project presents a deep learning-based handwritten alphabet recognition system developed using a Convolutional Neural Network (CNN) trained on the EMNIST Letters dataset. The system is capable of accurately classifying handwritten English alphabets and demonstrates practical applications in OCR-based automation systems.



\## Objectives



\- Recognize handwritten alphabets.

\- Train a robust CNN model.

\- Evaluate classification performance.

\- Apply the model to real-world recognition tasks.



\## Methodology



\### Data Collection



EMNIST Letters Dataset



\### Data Preparation



\- Dataset Merging

\- Label Cleaning

\- Image Reshaping

\- Rotation Correction

\- Pixel Normalization



\### Model Architecture



\- Conv2D

\- ReLU Activation

\- MaxPooling

\- BatchNormalization

\- Dense Layers

\- Dropout

\- Softmax Output



\### Training Configuration



\- Optimizer: SGD

\- Loss Function: Sparse Categorical Crossentropy

\- Epochs: 10

\- Batch Size: 128
