\# 🧠 YOLOv8 Object Detection – Smart Vision Systems



\## 🚀 Project Description

This project implements multiple AI-powered vision systems using YOLOv8 for object detection across different domains such as education, transportation, industry, wildlife, and retail.



\## 🛠️ Tech Stack

\- Python

\- Ultralytics YOLOv8

\- OpenCV

\- Matplotlib



\## 📌 Implemented Case Studies



\### 🎓 Smart Classroom Monitoring

Automates attendance using person detection.



\### 🚗 Smart Parking Surveillance

Detects vehicles and monitors parking spaces.



\### 🐘 Wildlife Conservation Monitoring

Identifies animals from captured images.



\### 🏭 Industrial Defect Detection

Detects faulty products on production lines.



\### 🛒 Retail Shelf Monitoring

Analyzes product availability on shelves.



\## 📊 Features

\- Image-based object detection

\- Real-time bounding box visualization

\- Object classification

\- Count-based analytics (retail case)



\## 📌 Output

Each case study produces annotated images with detected objects highlighted.



\## 🎯 Conclusion

YOLOv8 provides a fast and accurate solution for real-world object detection problems across multiple domains.
