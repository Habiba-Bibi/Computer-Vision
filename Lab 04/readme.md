**Image Enhancement using OpenCV**

This repository contains implementations of classical image enhancement techniques in Python using OpenCV.



The aim of this project is to improve image visibility under difficult conditions such as:



Low lighting

Fog or pollution

Underwater environments

Thermal satellite imaging

Techniques Used

Contrast Stretching

Gamma Correction

Histogram Equalization

CLAHE (Adaptive Histogram Equalization)

**Case Studies**

This project demonstrates real-world applications of image enhancement:



Underwater image enhancement for marine biology

Nighttime road scene improvement for autonomous vehicles

Low-light security camera enhancement

Foggy urban traffic monitoring

Thermal satellite image enhancement

**Tools and Libraries**

Python

OpenCV

NumPy

Matplotlib

Purpose

This project was developed as part of a Computer Vision Lab assignment to demonstrate practical applications of image enhancement techniques.
